# DEAD MEMORY

이전 회차의 자신이 다음 회차의 추적자가 되는 2D 탑뷰 액션 로그라이크의 플레이 가능한 초벌입니다. PC 키보드·마우스로 플레이하는 JavaScript + Canvas 프로토타입이며, 게임 실행에는 외부 패키지·API 키·외부 에셋이 필요하지 않습니다.

## 설치 없이 플레이 (GitHub Pages)

Pages 배포가 완료되면 **https://ghkdwo0202-crypto.github.io/dead-memory/** 에서 바로 플레이합니다. 플레이어는 Node.js나 파일 다운로드가 필요하지 않습니다. PC 키보드와 마우스를 사용하세요.

`main`에 푸시하면 `Deploy game to GitHub Pages` 워크플로가 테스트 후 게임 파일만 배포합니다. 진행 상황은 저장소의 **Actions**에서 확인합니다. 자동 사이트 생성이 권한 문제로 실패하면 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하고, Actions에서 해당 워크플로를 다시 실행하세요. 클라우드 환경 게시와는 별개입니다.

로컬 정적 배포 파일은 `npm run build:pages`로 `.local/pages/`에 생성합니다. 이 폴더에는 게임 HTML·JS·CSS만 포함됩니다. 사망 기록은 접속 주소별 브라우저 저장소에 유지되므로 로컬에서 플레이한 기록이 Pages로 이전되지는 않습니다.

## 개발용 로컬 실행

Node.js 22 이상(검증: 24.19.0)에서:

```sh
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 포트 변경은 `PORT=3001 npm start`로 가능합니다. HTML 파일을 직접 여는 대신 개발 서버를 사용하세요.

```sh
npm test       # 필수 12개 케이스를 포함한 전투·저장·AI 단위 테스트
npm run check # JavaScript 구문 검사
```

## 플레이

- WASD 이동, 마우스 조준, 좌클릭 기본 참격(누르고 있으면 연속 공격)
- 우클릭 무기 고유 액션: 강한 참격
- Space 대시: 2회 충전, 회당 2.5초 회복, 0.28초 무적
- Q / E / F 장착 스킬, H 도움말, Tab 빌드 정보, Esc 일시정지
- 최초 스킬 1개를 선택하고, 세 전투방을 정리하며 스킬을 획득합니다. 오른쪽 통로로 다음 방에 이동합니다.
- 적 처치 보상은 중복 장착을 막고, 가능하면 기존 스킬에 연결되는 후보를 최소 1개 포함합니다. 3슬롯이 찼으면 교체할 슬롯을 선택합니다.
- 첫 번째 기억을 **화염 참격**, 첫 전투 보상을 **뇌전 돌진**, 다음 보상을 **그림자 분신**으로 선택하면 U01 빌드를 만들 수 있습니다.
- **Q 화염 참격 → E 뇌전 돌진(적중) → F 그림자 분신**: R01을 거쳐 U01로 확장됩니다. 스킬 액션 종료 기준 2초, 확장은 1.5초입니다. 기본 공격과 대시는 연계를 끊지 않습니다.
- **뇌전 돌진 → 그림자 분신**: R05. **흡혈 낙인 → 화염 참격**: R11.
- 사망 기록은 `localStorage`의 `dead-memory.deaths.v1`에 최대 8개 보존됩니다. 같은 브라우저·같은 주소에서 다음 런을 시작하면 최신 기록의 추적자가 28초 후(또는 마지막 방 진입 시) 생성됩니다.
- 추적자는 사망 당시 스킬과 실제 성공한 공명을 계승합니다. 시야를 끊거나 패링해 후속 연계를 방해할 수 있습니다. 추적자 처치 시 실제 보유 스킬 계승 또는 체력 강화 보상을 받습니다.
- 마지막 방과 추적자를 정리하면 클리어합니다. 클리어 화면의 '기억을 남기기'는 다음 회차 체험을 위한 별도 기록 기능입니다.

브라우저 저장이 차단된 경우 해당 탭 안에서만 기록을 유지하며 결과 화면에 표시합니다. 사이트 데이터 삭제 시 기록도 삭제됩니다. 모바일 터치 조작은 지원하지 않습니다.

## 구조

- `src/data.js`: 스킬 20종, 고유 공명 20종, 상급 공명 8종 데이터. 구현 여부를 명시하여 미구현 기술이 보상에 나오지 않도록 합니다.
- `src/core.js`: 이벤트, 스킬 실행, 쿨다운, 공명 판정, 피해·흡혈·패링, 저장, 추적자 빌드·행동 선택, BFS 경로 탐색. 플레이어와 추적자가 같은 실행기를 사용합니다.
- `src/game.js`: 세 방 연결 맵, 입력, 전투 루프, 추적자 상태 전이, 보상·HUD, Canvas 시각 효과와 선택형 합성음.
- `src/style.css`, `index.html`: 한국어 게임 UI.
- `tests/combat.test.js`: 전투·공명·저장·추적자 규칙 회귀 테스트.
- `scripts/serve.mjs`: 의존성 없는 정적 개발 서버.
- [사양서 원문](docs/SPECIFICATION.md), [구현 범위와 다음 작업](docs/IMPLEMENTATION.md).

## 선택적 브라우저 검사

런타임에는 필요하지 않은 Playwright를 로컬에 설치한 다음, 개발 서버를 실행한 상태에서 검사합니다.

```sh
npm install --no-save --package-lock=false playwright@1.58.2
npm run test:browser
```

시스템 Chromium을 기본 사용합니다. 다른 경로는 `CHROMIUM_PATH`로 지정합니다. Chromium이 없다면 `npx playwright install chromium` 후 `CHROMIUM_PATH`를 다운로드한 브라우저 경로로 설정하세요. 브라우저 검사는 별도 임시 브라우저 프로필을 사용하여 플레이어의 실제 기록을 건드리지 않습니다.
