# MEAT MARKET v1.1 전환 계획

기존 엔진은 브라우저 Canvas 2D, 언어는 JavaScript ES modules, 검증 도구는 Node.js 테스트와 Playwright다. npm start 개발 서버 및 GitHub Pages 정적 배포는 유지한다. 기존의 이벤트 발행 구조, 시야 검사와 BFS 경로 탐색, 저장소 오류 처리와 브라우저 검사 방식을 재사용한다. Q/E/F 공명과 3방 구조는 새 명세의 기관·변이·생존 아레나로 대체한다. 이전 DEAD MEMORY 구현은 Git 커밋 ec3fb70/a77bc7d와 기존 사양서에 보존되어 있다. 기존 localStorage 키를 삭제하지 않는다.

1. 데이터: 기관 9종, 변이 12종, 상태이상·적·공격·런 설정을 src/data.js에 정의.
2. 헤드리스 게임 로직: src/core.js에서 키보드 입력 정규화, 공격 상태, 회피 버퍼, 공통 피해, 기관 장착, 이벤트 기반 변이를 구현. 렌더러 없이 테스트할 수 있도록 Game 시뮬레이션 제공.
3. 생존 루프: 4종 몬스터, 전조, 웨이브, 경험치 흡수, 레벨업 후보 3개, 성장에 따른 밀도 증가. 5분에 보스가 등장하는 짧은 런.
4. 화면: src/render.js의 Canvas 효과와 src/game.js의 키보드 전용 메뉴·HUD. 기관이 실제 몸에 표시되도록 부위별 모양 분리.
5. 추적자: 새 저장 스키마와 키, 같은 공격/기관 실행기를 사용하는 과거 빌드, 조건부 출현 및 메뉴 강제 출현 옵션.
6. 검증: 필수 22개 입력/전투/성장/추적자 케이스를 자동화하고 실제 Chromium에서 마우스 없는 시작·이동·공격·회피·보상·일시정지·저장 복원을 확인. 배포 산출물을 /dead-memory/ 하위 경로에서 검증.

완료 보고에서 실제 구현과 임시 패턴·아트·밸런싱을 구분한다. 클라우드 환경 자체는 게시하지 않는다.
