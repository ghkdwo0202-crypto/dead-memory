# KAGE//IN P3 — 횡스크롤 액션 전환 및 즉시 결인 인술 명세 v3.1
> Codex에 전달할 우선 개발 계약. **게임 구현 완료가 아닌 사양서**. 이 브랜치는 기존 P2 배포 브랜치 `downloads/kage-in-p2`에서 파생했습니다.

## 0. P3의 확정 변경 사항
1. 기존 **탑뷰/가상 공중 높이** 폐기. 이제 실제 중력·점프·낙하·플랫폼 충돌이 있는 **2D 횡스크롤 액션 게임**입니다. 실크송을 참조하는 것은 빠른 이동과 플랫폼 검술의 질감이며, 아트/캐릭터/레벨/기술을 복제하지 않습니다.
2. **각 속성 키를 단독으로 한 번 누르면 기본 단일 인술이 즉시 발동**합니다.
3. **속성 인을 3개 이어 누르면 세 번째 입력 순간 혼합 인술이 즉시 발동**합니다. 기존 V 확정·C 발동·인술 저장 슬롯을 삭제합니다. FFF, WWW처럼 동일 속성 3개는 상위 단일 인술 자동 발동.
4. 핵심 액션은 **검술(Z)·회피(X)·점프(Space)·근접 피니시(C) + A/S/D/F 결인**입니다. 마우스와 WASD 이동은 금지.
5. P3 시작 전에 실제 P2 산출물을 식별해야 합니다. GitHub 브랜치 `downloads/kage-in-p2`의 `downloads/KAGE-IN.zip`은 P2 배포물이며, 같은 브랜치 최상위 `src/`/README는 이전 MEAT MARKET 코드를 포함할 수 있습니다. ZIP을 열어 P2 닌자 구현 원본과 실행 경로를 조사한 뒤 새 전환 작업 브랜치에서 수정하세요. **이전 P2 및 main은 덮어쓰지 마세요.**

## 1. P3 조작과 입력 우선순위
| 입력 | 기능 |
|---|---|
| ←/→ | 좌우 달리기, 바라보기 |
| ↑ | 위쪽 공격/인술 조준, 이동축 아님 |
| ↓ | 공중 빠른 낙하, ↓+Space는 일방향 발판 내려가기 |
| Space | 점프, 코요테 타임과 점프 버퍼; 공중 공격 |
| Z | 지상 3연속 검격 / 공중 2타, 홀드 연타 |
| X | 지상/공중 대시, 실제 회피 성공 반격 창 |
| C | 상향 띄우기(지상)/하향 격추(공중), 2.8초 쿨다운 |
| A | 화둔 인 입력, **첫 입력 시 즉시 화염 수리검** |
| S | 수둔 인 입력, **첫 입력 시 즉시 물 베기** |
| D | 뇌둔 인 입력, **첫 입력 시 즉시 전광침** |
| F | 풍둔 인 입력, **첫 입력 시 즉시 진공 수리검** |
| Enter/Esc | UI 확인/일시정지 |
| V | 사용 안 함. 전투에서 결인 확정 키로 사용 금지 |

- 방향키 조작을 WASD로 변경하지 마세요. 브라우저 키 기본 동작(방향키·Space 스크롤)을 차단하세요.
- 결인은 keydown **에지만** 수집합니다. 키 홀드 자동 반복은 인 입력으로 취급하지 않습니다.
- 공격·이동·공중 중에도 결인 입력을 받되 시전 불가 상태에서는 최대 0.18초 버퍼만 허용하고, 버퍼 초과 시 정확한 실패 피드백을 표시합니다.
- 동시에 V+C를 누를 경우 기존 V 처리 코드는 호출하면 안 됩니다. C는 근접 피니시 전용입니다.
- 모든 HUD·보상 UI는 마우스 없이 조작할 수 있어야 합니다.

## 2. **핵심: 단일 즉발 + 3인 자동 발동 상태 머신**
**애매함 해소:** 첫 번째 인만 단일기를 즉시 사용합니다. 두 번째 인은 조합 진행만 하고, 세 번째 인은 완성된 인술을 **자동 발동**합니다. 두 번째 키로 혼합 인술을 발동하면 세 번째 인 레시피와 충돌하므로 그러지 않습니다.

### 입력 처리 (정규 규칙)
```js
// conceptual algorithm; adapt to existing engine, do not paste untested
function onElementKey(element, now) {
  if (now > state.expiresAt) state.seals = [];
  state.seals.push(element);
  state.expiresAt = now + 0.75;
  if (state.seals.length === 1) requestCast('SINGLE_' + element, now); // instant
  if (state.seals.length === 2) previewPossibleRecipe(state.seals);   // NO cast
  if (state.seals.length === 3) {
    const recipe = canonicalMultiset(state.seals); // F,W,L,V symbols
    state.seals = []; state.expiresAt = 0;
    requestCast(RECIPE_TO_SPELL[recipe], now); // immediate, no V or C
  }
}
```
- 입력 대기 유효기간: 마지막 인 기준 **0.75초**. 시간 만료 후 누르는 속성 키는 새로운 1번 인이므로 단일기를 다시 시도합니다.
- **첫 인 단일기**는 쿨다운 1.0초(속성별 독립)이며, 단일기가 쿨다운이어도 결인 링버퍼에는 정상 입력됩니다.
- **3인 조합 인술**은 개별 쿨다운(5~10초 초기값) + 전역 시전 락 0.18초. 단일기 쿨다운과 독립입니다.
- 세 번째 입력 시 조합이 쿨다운이어도 **버퍼는 초기화**, 쿨다운은 소비되지 않으며 HUD에서 불발 이유를 표시합니다.
- 인술 시전 가능한 상태가 아닌 경우 버퍼 최대 0.18초. 피격 경직으로 버퍼가 끝나면 불발을 표시하고 이벤트를 버립니다.
- 첫 단일기 직후 0.18초 이내 세 번째 인이 완성될 경우, 단일기 동작의 회복을 0.18초 이하로 제한하거나 취소창을 허용해 **입력한 즉시 조합이 눈에 띄게 발동**되도록 해야 합니다. 시전 중 요청을 잃지 않도록 캐스트 요청 큐를 구현합니다.
- 두 속성을 반복하면 A→S→S는 화/수/수 혼합 인술. 순서는 중요하지 않아 S→A→S도 같은 혼합기입니다.
- FFF/WWW/LLL/VVV는 상위 단일 속성기로 자동 발동합니다. 4속성 3인 멀티셋은 정확히 20개입니다.
- `A` 한번만 누른 후 0.75초 기다리면 **기본 화둔만 사용**합니다. 같은 키를 3회 짧게 누르면 기본기 1회 + 상위 단일 속성기 1회.
- 결인 이외에 준비/저장/호출 UI는 존재하지 않습니다. HUD는 0~2개 인과 세 번째 입력 예측, 각 인술 쿨다운을 표시합니다.

### 시전 충돌·이벤트 선후 관계
- 세 번째 키다운마다 결인 이벤트 1회, 기술 생성 최대 1회. 키 리피트는 무시.
- 공중/대시/공격 상태의 시전은 기술의 allowedStates와 취소 가능 시간에 따라 처리합니다.
- 캐스트 큐는 최대 1개의 인술 요청만 보관(가장 오래된 확정 인술을 우선 실행, 두 번째 요청은 피드백과 함께 거부); 결인 입력 자체는 물리 이동을 중단하지 않습니다.
- 적 공격 반응/속성 중첩은 인술에서 다시 인술을 자동 생성하지 않습니다. 시전마다 독립 attackInstanceId를 부여.
- 오디오·결인 피드백의 성공과 불발 표시를 확실히 구분합니다.

## 3. 실크송 같은 **물리 횡스크롤 액션**의 필수 조작 품질
P3는 탑뷰 카메라만 옆으로 돌려서는 안 됩니다. 플레이어와 적의 위치·공격 판정·추적은 모두 **월드 2D X/Y + 중력**으로 다시 맞춰야 합니다.

| 항목 | 초기 테스트값 | 규칙 |
|---|---|---|
| 물리 틱 | 60Hz fixed timestep | 렌더와 충돌 결정 분리 |
| 중력 | +1900 px/s², 아래 양수 | 바닥/벽 충돌 |
| 이동 속도 | 270 px/s | 좌우만 기본 이동 |
| 지상 가속/감속 | 2400/3000 px/s² | 손 뗄 때 빠른 정지 |
| 공중 가속 | 1550 px/s² | 공중 방향 전환 가능 |
| 점프 초기 속도 | -680 px/s | Space 길이에 따라 높이 달라짐 |
| 코요테/점프 버퍼 | 0.10/0.12초 | 플랫폼 액션 필수 |
| 점프 홀드 시간 | 0.18초 | 조기 손 떼기 시 상승속도 제한 |
| 대시 | 620px/s · 0.17초 | 방향은 좌/우, 벽 통과 금지 |
| 회피 무적 | 0.025~0.125초 | 1회 적 공격당 회피 성공 판정 1회 |
| 공중 대시 | 착지 전 1회 | 착지 시 복구 |
| 캐릭터 충돌 | 너비 28 × 높이 52px | AABB 또는 capsule, swept 충돌/서브스텝 |

- 점프/낙하는 실제 물리 속도입니다. 기존 `airHeight` 값은 **비주얼 전용 변수로도 액션 충돌에 사용하지 않습니다**.
- 바닥, 벽, 천장, 일방향 플랫폼, 낙사/체크포인트, 발판에서 착지 판정이 필요합니다.
- Space는 점프/방향키 조합으로 발판 아래로 내려갈 수 있지만, 일반 ↓ 입력만으로 캐릭터가 내려가지 않습니다.
- `↑+Z`: 상향 베기. `↓+Z` 공중: 하향 베기. 적중 시 1회 반동 점프(포고, -430px/s); 동일 대상 0.2초 재타격 제한.
- 공격 조준은 좌/우 바라보기 + ↑/↓ 변형. **뒤쪽 자동 조준 금지**; 시야나 벽을 관통하는 근접 돌진 금지.
- 플랫폼 전투는 지형을 이용하게 합니다: 상향 베기·하향 공격·착지 직후 검격·대시로 단차 넘기. 한 화면에 벽이 많을 때 카메라 가림이나 공격 판정 누락 금지.

## 4. 근접 액션 사양 — 인술 없이도 재미있어야 함
- 지상 Z1: 전방 100px 베기, 준비/활성/후딜 0.07/0.08/0.13초, 기본 피해 16.
- Z2: 상향 궤적 95px, 0.08/0.07/0.15초, 피해 18.
- Z3: 전방 110px 띄우기, 0.11/0.08/0.19초, 피해 23. 소형 적에 실제 수직 속도 부여. 보스는 고도 조절 대신 경직 게이지 증가.
- 공중 Z는 2타(수평·대각 하향). ↓+Z 적중으로 포고, 지상 복귀가 자동 콤보 피니시가 되도록 착지 0.2초 짧은 연계창.
- X 직후 0.35초 이내 Z는 전방 35px 돌파 베기. **추가 무적 없음**.
- 완벽 회피 = 무적 중 실제 공격 판정이 충돌했으나 피해를 막은 경우. 성공 시 0.55초 C 반격창. 단순 X 입력만으로 성공 처리 금지.
- C 지상: 상향 발도; 공중: 하향 격추 베기. CD 2.8초, 적중 여부와 관계없이 실제 사용 시 쿨다운 소비. 지형/벽을 관통하지 않음.
- Z 홀드 반복 공격은 유지, 추가 Q/E/F류 강제 콤보 금지.
- 소형 적 공중 유지 최대 1.0초, 최대 5공중 히트·재띄우기 1회, 이후 낙하 면역 1.5초. 보스/무거운 정예는 실제 공중 띄우기 면역.
- 피격·히트스톱·카메라 연출은 실제 공격 판정과 분리. 타격 프레임 0.04~0.065초 정지, 적 공격 전조는 FX보다 위에 그리기.
- 회피·공중·추격·포고·C 반격 연계 각각 데모 테스트 장면 구성.

## 5. **단일 속성 인술 4개** (첫 키 입력 즉시)
| 실제 키 | Skill ID | 기술 | 행위 | CD |
|---|---|---|---|---|
| A | SINGLE_FIRE | 화염 수리검 | 바라보는 방향 230px 화염탄, 점화 3초·기본 피해 13 | 1.0초 |
| S | SINGLE_WATER | 물 베기 | 전방 95px 물결 참격, 젖음 4초·약한 밀기 | 1.0초 |
| D | SINGLE_LIGHTNING | 전광침 | 수평 180px 뇌침, 적 1명 관통·감전 2.5초 | 1.0초 |
| F | SINGLE_WIND | 진공 수리검 | 전방 195px 풍날, 소형 적 띄우기, 공중에선 하향 넉백 | 1.0초 |

- 단일 기술도 지상/공중 모두 가능. ↑를 누른 경우 최대 55° 상향 방향 조준. 아래를 누른 채 공중에서 사용하면 허용 기술은 하향 발사.
- 4개 기술은 단독 액션으로도 가치 있어야 합니다. 화염 표식→Z, 수둔 밀기→돌진, 뇌둔 감전→공중 C, 풍둔 띄우기→포고가 각각 작동해야 합니다.
- 첫 입력 시 기본 인술만 발동해도 3인 버퍼는 유지됩니다.

## 6. 3개 인 완성 즉시 발동하는 **20개 조합**
설계 데이터 표기의 F/W/L/V는 각각 Fire/Water/Lightning/Wind이고 **실제 입력키 A/S/D/F와 다릅니다**. 임의 코드 정렬 순서는 F,W,L,V를 강제하고, 실제 문자열 인코딩을 키 이름과 혼용하지 마세요.
| 조합 | 인술명 | 지상 판정 | 공중 변형 |
|---|---|---|---|
| `FFF` | 홍련폭 | 전방 부채꼴 폭발·점화 | 공중 시 수평 원호 폭발 |
| `WWW` | 격류진 | 플랫폼 표면을 타고 가는 파도·젖음 | 공중 시 수평 물칼날 |
| `LLL` | 천뢰격 | 전방 적 낙뢰·감전 | 공중 시 적을 향한 수직 낙뢰 |
| `VVV` | 진공참 | 상승 칼바람 2개·띄우기 | 공중에서 아래 적 격추 |
| `FFW` | 증기폭쇄 | 근거리 증기 폭발·시야 연출(적 시야 방해만) | 공중 1회 후방 반동 |
| `FFL` | 폭염낙뢰 | 전방 3연속 지연 낙뢰·점화 폭발 | 공중에서 아래 지상에 번개 낙하 |
| `FFV` | 화염용권 | 전진하는 화염 회오리·띄우기 | 공중에서 전방 수평 이동 |
| `FWW` | 열수분출 | 플랫폼 위 3개의 순차 열수 기둥 | 공중에선 하향 물칼날 3개 |
| `WWL` | 도전수옥 | 젖은 적 최대 3 연결 감전 구체 | 공중 대상까지 전도 |
| `WWV` | 빙결수리검 | 전방 얼음 수리검 3개·둔화 | 공중 시 사선 하향 투척 |
| `FLL` | 열뢰창 | 좁은 관통 번개 창·점화 추가타 | 공중에서도 직선 관통 |
| `WLL` | 뇌수쇄도 | 플랫폼 표면 감전 웅덩이 2.5초 | 공중 시 착지 위치 낙뢰 |
| `LLV` | 순뢰보 | 전방 140px 전격 돌진 베기, 벽 정지 | 공중 수평 돌진, 착지 리셋과 무관 |
| `FVV` | 열풍쇄 | 전방 X자 화염 절단 두 타 | 공중에서도 전방 X자 |
| `WVV` | 한풍질주 | 전방 100px 이동+얼음 궤적 | 공중은 하강 얼음 파편 |
| `LVV` | 풍뢰선 | 전방 두 선로에 교차 전격 베기 | 공중 시 대각선 두 전기선 |
| `FWL` | 멸진뇌폭 | 젖음·점화 소비 후 전격 광역 폭발 | 공중 아래쪽으로 우선 폭발 |
| `FWV` | 환류염무 | 플레이어 주위 증기+불꽃 이중 원 | 공중 이동속도 저하 20% |
| `FLV` | 뇌화비연 | 전방 최대 3명 고속 3연속 발도, 벽 정지 | 공중 추격 연계 가능 |
| `WLV` | 천우뇌옥 | 전방 폭풍 감옥 2.5초·젖음 감전 | 공중 적 0.5초 고정 후 정상 낙하 |

### 조합 기술 구현 규칙
- 인술마다 고유 ID `NIN_001 ... NIN_020`, 공격 형태, 공격 범위, 준비·활성·후딜, 쿨다운(5~10초), allowedStates, 충돌 규칙, 최대 활성 개체, FX가 있어야 합니다.
- 이전 v3.0의 **20개 레시피 의미와 이름을 유지**하되 횡스크롤용으로 탄도/플랫폼 지형/공중 상태에 맞게 조정합니다. 외형이 다른 단순 데미지 투사체 20개로 퉁치지 않습니다.
- 점프 중 지상 장판 기술은 현재 하단의 충돌 가능한 플랫폼에만 생성하고, 없으면 문서에 지정된 공중 대체 기술 발동. 발판이 없는 허공에 지면 장판 생성 금지.
- 지면 대상 20개 중 `격류진`/`뇌수쇄도` 등은 플랫폼 고도를 기준으로 이동 및 충돌.
- 직접 공격이 적중한 적에게 부여된 원소 상태는 다른 인술을 적중시킬 때 환경 반응을 생성합니다. **속성 조합 레시피와 적에게 걸린 속성의 반응은 서로 다른 시스템**입니다.

## 7. 원소 반응 (액션을 바꿔야 함)
| 반응 | 조건 | 물리/전투 효과 | 재발동 제한 |
|---|---|---|---|
| 수→뇌 전도 | 젖음 중 뇌 적중 | 인접 적 최대 2에게 전류, 경직 짧게 | 대상당 0.7초 |
| 화→풍 확산 | 점화 중 풍 적중 | 전방 화염선이 지면/공중을 가르며 확산 | chain root당 1회 |
| 수→풍 빙결 | 젖음 중 풍 적중 | 0.7초 작은 적 이동 정지, 공중 적 낙하 느림 | 보스는 둔화만 |
| 화→수 증기 | 점화 중 수 적중 | 증기 폭발 넉백·공중 튕김, 1.1초 FX | 대상당 0.8초 |
| 뇌→화 과부하 | 감전 중 화 적중 | 대상 근처 충격 폭발, 공중 적 약하게 띄움 | 대상당 0.8초 |
| 풍→뇌 추격 표식 | 풍 표식 중 뇌 적중 | 짧은 표적 추적 번개, 위치 추적 1회 | root당 1회 |

- 이벤트 처리: 직접 타격→상태 적용→반응→이동/경직→처치→스타일·보상. 반응이 다시 반응을 발동시키지 않음.
- `CombatEvent` chainDepth 최대 4, 이벤트 64개; 동일 대상·동일 공격 인스턴스 중복 피해 방지. 플레이어와 적이 겹쳤을 때 반응 지연 중 무한 제어 금지.
- 보스/대형 적은 띄우기·빙결 대신 경직 게이지로 변환. 보스에게 해당 속성 빌드가 완전히 무효화되지 않도록 피해·경직 기여는 남깁니다.

## 8. 액션 빌드와 성장 (P3 후반 단계)
- 검술 형태 4종: **거합**(Z 홀드 충전 시 관통 발도), **연참**(Z1/Z2 빠른 반복 대신 마지막 4타), **쌍검**(근거리 다중 타격과 좁은 거리), **체술**(Z3 띄우기/공중 포고 강화).
- 회피 진화 4종: **잔상**(회피 후 지연 참격), **역습**(PerfectDodge 후 C 확대), **질주**(X 후 Z 파고들기 강화), **낙하**(공중 X 후 ↓+Z 격추).
- 원소 각인 업그레이드 8종: 점화 화염선, 젖음 전도 1명 증가, 감전 경직, 풍 공중 높이 제어, 연쇄 쿨다운 감소(상한), 인술 장판 지속, 근접 적중 시 단일 인술 시너지, 공중 인술 추가 칼날.
- 장착 슬롯: 검술 1, 회피 1, 각인 2. 성장 3택은 방향키·Enter로 고르며 인술의 기본 레시피는 RNG 잠금 대상이 아닙니다.
- **특정 완성 빌드를 고집하기보다 공중 콤보·전격 이동·구역 제어·연타형 등 8가지 이상 구별되는 행동 루프**를 P3 최종 플레이테스트에서 검증합니다.
- 스타일 등급 D→SS는 근접·공중·대시·원소반응을 다양하게 사용하는 데 보상. XP +0~10% 이외 필수 보상 잠금 금지.

## 11. 테스트 매트릭스 / 완료 판정
1. 좌/우만 지상 이동하고 ↑/↓는 조준/낙하. 중력/점프/착지와 실제 Y축 지형 충돌 존재; airHeight로 적을 띄우는 가짜 높이 금지.
2. Z 홀드 3타, 공중 Z 2타, ↑Z·↓Z, X 대시, C 피니시 각각 공격 판정과 타격 피드백.
3. PerfectDodge는 실제 적 공격 무력화 때만 발생. 코요테/점프버퍼 허용 오차 검증.
4. 첫 `A` = FIRE BASIC 1회 즉시, `S` = WATER BASIC, `D`=LIGHTNING BASIC, `F`=WIND BASIC. 한 키다운 두 번 방출 금지.
5. `A→S→D` = FWL 조합 자동 발동, 같은 인의 순열 6가지 동일 인술; **V/C/Enter 불필요**.
6. `A→A→A` = 첫 A 기본 화둔 + 셋째 A 상위 화둔, 두 번째 A 단일 발동 없음.
7. 0.75초 초과 시 조합 초기화 후 새로운 첫 단일기. 다른 키 조합 중에도 Z/Space/X 조작이 유지됨.
8. 20개 고유 레시피가 모두 시전되며 레지스트리 중복 없음; 벽 뒤 표적은 시선·충돌 규칙 적용.
9. 혼합 인술 쿨다운 실패 시 버퍼 정리·CD 불변·UI 불발 알림. 단일기 쿨다운은 조합 성립을 방해하지 않음.
10. 실제 수면 없는 플랫폼 위에서 지상 장판 소환하지 않음. 보스 띄우기 불가능, 경직 환산.
11. Wet/Fire/Lightning/Wind 반응 루프 유한, 각 반응별 시각·물리 효과 존재.
12. 메뉴와 게임은 키보드만으로 운영. 기존 MEAT MARKET P2 ZIP과 배포 산출물 보존.
13. 60fps 목표에서 FX/엔티티 한도를 넘지 않도록 가드. 화면 흔들림·플래시 옵션 제공.
14. 자동화 테스트와 실제 브라우저 플레이테스트 결과 모두 보고; 자동화 통과만으로 '손맛 검증 완료' 주장 금지.

## 12. 범위 차단 및 충돌 결정
- 기존 v3.0의 `V로 Invoke`, `C로 인술 발동`, 2개의 기억 스킬 슬롯, 탑뷰 8방향 이동, 가상 `airHeight`는 **P3에서 폐기**합니다.
- '첫 인 단일 시전'은 단일 인술을 사용하는 직관성과 3인 결인 조합을 공존시키는 규칙입니다. 이로 인한 첫 입력 후 0.75초 재입력 대기 UX는 플레이테스트하고 조정 가능한 값으로 두세요.
- 2인 조합 즉시 발동을 허용하면 3인 조합의 앞부분을 소비할 수 있어 **사용하지 않습니다**. 혼합 인술은 정확히 3개가 완성될 때만 발동합니다.
- 기존 손맛을 갖춘 횡스크롤 프로토타입이 없다면 P3-A/B를 먼저 해야 합니다. 단순 화면 회전 또는 가짜 2.5D 공중 상태를 유지한 채 20개 인술만 추가하는 구현은 **사양 미달**입니다.
- 코드 전환 PR은 다른 브랜치로 별도 제출하고 기존 P2 브랜치, main을 즉시 수정하지 마세요.
