# DEAD MEMORY — Codex 개발 지시서

## 1. 프로젝트 개요

**프로젝트명:** DEAD MEMORY  
**장르:** 2D 탑뷰 액션 로그라이크  
**플랫폼:** PC  
**핵심 특징:** 스킬 조합에 따른 커맨드 연계형 특수기와, 이전 플레이에서 사망한 캐릭터가 추적자로 등장하는 시스템

### 핵심 게임 루프

1. 던전에 입장한다.
2. 몬스터를 처치하고 스킬을 획득한다.
3. 스킬을 조합해 공명 특수기를 발견한다.
4. 전투 중 스킬을 특정 순서로 사용해 특수기를 발동한다.
5. 과거에 사망한 캐릭터가 추적자로 등장한다.
6. 추적자를 처치하면 과거의 스킬 또는 공명 보상을 획득한다.
7. 플레이어가 사망하면 현재 빌드와 전투 기록이 저장된다.
8. 이후 플레이에서 해당 캐릭터가 추적자로 등장한다.

## 2. 개발 원칙

- 기존 프로젝트가 있다면 먼저 코드와 폴더 구조를 분석한다.
- 현재 사용 중인 엔진, 언어, 프레임워크를 유지한다.
- 기존 기능을 임의로 삭제하거나 파괴하지 않는다.
- 데이터 기반 구조로 설계해 스킬과 공명을 쉽게 추가할 수 있도록 한다.
- 플레이어와 추적자가 동일한 스킬 실행 시스템을 사용하도록 한다.
- 공명 판정과 시각 효과를 분리한다.
- 최초 목표는 완성 게임이 아니라 실제 플레이 가능한 수직 슬라이스(Vertical Slice)다.
- 구현되지 않은 기능을 완료했다고 보고하지 않는다.

## 5. 공명 시스템 (Resonance System)

### 핵심 규칙

플레이어가 장착한 스킬을 특정 순서로 사용하면 자동으로 공명 특수기가 발동한다.

특수기 전용 입력 버튼은 사용하지 않는다.

공명 유형:

- 일반 공명: 스킬 태그에 따른 공통 연계
- 고유 공명: 특정 스킬 2개로 발동하는 전용 특수기
- 상급 공명: 스킬 3개를 연계해 발동하는 강화 특수기

### 연계 시간

- 2스킬 공명: 2.0초
- 3스킬 확장: 1.5초
- 연계 시간은 이전 스킬의 유효 액션 종료 시점을 기준으로 계산한다.
- 각 공명의 별도 조건이 있다면 이를 우선 적용한다.

### 공명 판정

공명 시스템은 다음 이벤트를 지원해야 한다.

- SkillUsed
- SkillHit
- PerfectParry
- DashEvaded
- StatusApplied
- ResonanceTriggered
- ComboExpired
- ComboInterrupted

공명 레시피는 입력 순서, 시간 제한, 발동 조건, 실행 효과를 데이터로 관리한다.

공명 조건이 충족되지 않으면 일반 스킬로 처리한다.

### 중요한 처리 규칙

- 2스킬 공명은 두 번째 스킬 사용 시점 또는 레시피에 지정된 적중 시점에 확정한다.
- 상급 공명은 기존 2스킬 공명을 확장한다.
- 상급 공명 발동 시 이미 적용된 피해를 중복 계산하지 않는다.
- 공명은 구성 스킬의 쿨다운을 따른다.
- 기본 공격, 이동, 일반 대시는 공명을 중단하지 않는다.
- 공명 중 캐릭터 사망 또는 강제 행동 불능 시 연계를 종료한다.
- 같은 입력에 여러 레시피가 일치하면 상급 공명, 고유 공명, 일반 공명 순으로 우선 처리한다.
- 발동 완료된 공명은 동일 이벤트에서 중복 발동하지 않도록 한다.

1차 구현 대상은 U01이다.

### U01 상세

**뇌염환영참**

입력: A01 → M01 → S01

1. 화염 참격을 사용한다.
2. 2초 이내에 뇌전 돌진을 사용한다.
3. 돌진이 적중하면 R01 뇌염 돌파가 확정된다.
4. 돌진 액션 종료 후 1.5초 이내에 그림자 분신을 사용한다.
5. 분신이 돌진 종료 지점에 생성된다.
6. 분신들이 화염 참격을 복제하여 주변 적을 공격한다.
7. 앞서 발생한 돌진 피해는 다시 계산하지 않는다.

실패 시 각 스킬의 일반 효과를 유지한다.

## 8. 스킬 획득 시스템

### 획득 방식

- 시작 시 스킬 후보 3개 중 1개 선택
- 일반 전투 보상으로 스킬 획득
- 정예 몬스터 처치 시 희귀 스킬 후보 제공
- 기억 제단에서 스킬 교체 또는 강화
- 추적자 처치 시 계승 스킬 또는 공명 관련 보상 제공

### 보상 후보 생성

스킬 후보 3개 중 최소 1개는 현재 보유 스킬과 공명이 가능한 후보로 생성한다.

단, 실제로 가능한 조합이 없거나 후보 풀이 소진된 경우에는 일반 랜덤 후보를 사용한다.

보상 UI에는 다음 정보를 표시한다.

- 스킬 이름
- 스킬 효과
- 쿨다운
- 현재 스킬과의 공명 가능 여부
- 완성 가능한 공명 이름
- 상급 공명 완성 여부

### 스킬 슬롯

- 최대 3개 장착
- 빈 슬롯이 있으면 즉시 장착 가능
- 슬롯이 가득 찼다면 기존 스킬과 교체 가능
- 교체 시 사용 가능한 공명 목록을 즉시 갱신
- 동일 스킬의 중복 장착은 기본적으로 불가

## 9. 추적자 시스템 (Past Self Hunter)

플레이어가 사망하면 현재 캐릭터의 빌드와 전투 기록을 저장한다.

다음 런부터 해당 기록을 기반으로 추적자가 등장한다.

### 저장 데이터

- RunID
- DeathID
- WeaponID
- EquippedSkillIDs
- AvailableResonanceIDs
- SuccessfulResonanceIDs
- ComboUsageCounts
- CombatStyle
- DeathFloor
- DeathCause

### 추적자 AI 상태

- Patrol: 배회
- Investigate: 소음 조사
- Search: 마지막 목격 위치 수색
- Chase: 플레이어 추격
- Combat: 전투
- Retreat: 후퇴
- Recover: 재정비

### 추적 규칙

- 추적자는 플레이어의 정확한 위치를 항상 알지 못한다.
- 시야, 소음, 마지막 목격 위치를 활용한다.
- 방 사이 이동은 실제 경로 탐색을 사용한다.
- 추적자 접근 시 소리와 시각적 징후를 제공한다.
- 플레이어가 시야를 끊으면 마지막 목격 위치를 조사한다.
- 후퇴한 추적자의 남은 체력은 같은 런에서 유지한다.

### 공명 계승 규칙

- 추적자는 사망 당시 장착한 스킬 3개를 사용한다.
- 플레이어가 실제로 성공한 공명을 우선 사용한다.
- 사용 횟수가 높은 공명에 더 높은 선택 가중치를 부여한다.
- 성공 기록이 없는 상급 공명은 사용하지 않는다.
- 추적자의 공명도 플레이어와 동일한 조건을 만족해야 한다.
- 공격에는 명확한 전조와 회피 가능한 타이밍을 제공한다.
- 공명 조건을 방해받으면 상급 공명으로 이어지지 않는다.

### AI 구현 원칙

머신러닝은 필요하지 않다.

저장된 전투 통계를 기반으로 미리 정의된 전투 행동의 가중치를 조절하는 방식으로 구현한다.

## 10. 추적자 보상

추적자를 처치하면 기억 강탈 보상 화면을 표시한다.

가능한 보상:

1. 추적자의 스킬 하나 획득
2. 추적자의 공명 레시피 발견
3. 현재 빌드와 연결되는 특수 강화 획득

보상 후보는 추적자의 실제 보유 스킬과 공명 기록을 기준으로 생성한다.

불가능한 조합이나 존재하지 않는 레시피를 보상으로 생성하지 않는다.

## 13. 필수 테스트 케이스

다음 테스트를 반드시 작성하거나 실행한다.

1. A01 → M01 순서로 사용하면 R01이 발동한다.
2. M01 → A01은 R01을 발동시키지 않는다.
3. 연계 제한 시간을 초과하면 공명이 발생하지 않는다.
4. A01 → M01 → S01로 U01을 발동할 수 있다.
5. U01 발동 시 R01 피해가 중복 적용되지 않는다.
6. 공명 실패 시 일반 스킬이 정상적으로 발동한다.
7. 쿨다운 중인 스킬은 공명에 사용되지 않는다.
8. 스킬 교체 시 공명 후보가 갱신된다.
9. 플레이어 사망 시 빌드가 정상 저장된다.
10. 추적자는 저장된 스킬과 공명만 사용한다.
11. 추적자의 콤보 조건을 방해하면 후속 공명이 취소된다.
12. 게임 재시작 후에도 사망 기록을 불러올 수 있다.
