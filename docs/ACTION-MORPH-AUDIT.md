## 해석/충돌 처리

- PATH_25 X는 카드에 이득 대신 소환체 위험이 적혀 있다. T2 X는 플레이어 회피를 보존하면서 새끼가 표적 공격을 유지하고 함께 회피하지 않는 명령으로 구현한다. 일반 소환체는 플레이어 회피 시 잠시 회수/회피한다. 새끼에는 실제 HP와 적 전조/투사체 피격을 구현하여 교환이 실재하도록 한다.
- PATH_06은 Z를 놓을 때 발사하는 충전이다. 이동 중에는 축적하지 않고 속도가 35%가 되며, 0.45초 미만은 기본 탄으로 발사한다. C 표식 의존성이 약점의 눈 자체와 충돌하므로 경로의 정조준 적중이 잠시 표식을 남긴다. 표식도 표적도 없으면 기본 C로 처리한다.
- 경로가 장비 조건을 잃으면 저장한 티어는 보존하고 기본 Z/X/C로 복귀한다. 유료 티어를 자동 삭제하거나 다른 경로로 바꾸지 않는다.
- 미구현 28개는 `implemented:false`, 보상/시험 장착 불가. 메타데이터 테스트 통과를 실제 액션 구현으로 보고하지 않는다.
- v1.3의 18변이/8적응, 나머지 기관과 전체 저장 스키마 이전은 별도 범위다. 기존 MUT ID 의미를 이번에 덮어쓰지 않는다.

## 순서와 단계 보고

A: 감사/스키마/검증 → B: 공통 resolver/수명/저장/보상 → C1 PATH_01 → C2 PATH_06 → C3 PATH_17 → C4 PATH_25. 각 단계에 단위 테스트와 실행 결과를 기록한다. 네 경로 확인 후 이번 변경을 종료하고, 다음 변경에서 남은 경로를 계열별 4개 단위로 진행한다. 32개를 한 번에 구현하지 않는다.
