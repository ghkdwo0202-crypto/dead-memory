# MEAT MARKET v0.2 구현 현황

기존 JavaScript ES modules + Canvas 2D 엔진, Node 개발 서버, 정적 GitHub Pages 배포를 유지했다. 공통 이벤트 발행 구조와 시야·BFS 경로 탐색, 브라우저 저장/테스트 방식을 재사용했다. 기존 Q/E/F 공명 게임은 명세에 따라 기관·변이 기반 생존 게임으로 전환했다. 이전 구현은 Git 커밋 ec3fb70/a77bc7d, `docs/DEAD-MEMORY-IMPLEMENTATION.md`, `docs/SPECIFICATION.md`에 남아 있다.

## 구현 완료

- 방향키 8방향/대각 정규화, Z 누름/유지 공격, X 2충전 회피, C 팔 특수 공격. 마우스 조준·WASD·Q/E/F 입력 없음.
- 이동과 공격 동시 입력, 공격 준비/활성/회복, 방향 보정 거리/각도/고정 시간, 마지막 이동 방향, 입력 버퍼, 회피 취소 구간, 0.22초 회피/0.16초 무적/2.5초 재충전.
- 직접 공격 넉백·경직, 짧은 히트스톱, 피격 피드백. 피격 후 0.45초 보호로 적이 겹쳤을 때 즉사를 완화.
- 팔 2종(톱날/가시), 등 3종(촉수/포탑/회전 칼날), 심장 2종, 눈 2종. 슬롯별 외형, 자동 공격과 표적 우선순위, 교체 시 기존 변이 제거.
- 별도 데이터의 기관 필수 필드와 변이 12종. 분열/관통/폭발/전염/흡혈/복제/가속/실제 회피 반격/처형/집중/귀환/연쇄 효과가 전투에 연결됨. 전염은 출혈을 생성할 수 있는 톱날 팔에만 제공.
- 출혈·독·감전·둔화·기절의 공통 지속/중첩/갱신/면역/틱 처리. 톱날 특수기의 짧은 기절은 보스에게 면역.
- 전투 이벤트 9종. 출처/루트 ID, 결정적 큐 처리, 변이별 내부 쿨다운/횟수 제한, 최대 깊이 4와 루트당 이벤트 64개로 재귀 제한.
- 일반 몬스터 4종, 명확한 공격 전조, 원거리 독 투사체, 자폭/사망 폭발과 몬스터 간 피해. 시간에 따라 증가하는 웨이브 및 적/투사체/경험치 수 제한.
- 경험치 오브/흡수, 레벨업 정지, 유효 보상 3개와 가능한 경우 시너지 후보 포함, 신규 기관·교체·변이·수치 강화. 방향키/Enter로 선택 완료.
- HP/XP/레벨/회피/특수 쿨다운/기관/변이/생존 시간/처치/몸값 HUD, 도움말·일시정지·결과·재시작을 키보드로 조작.
- 새 `meat-market.deaths.v1` 기록에 기관·변이·공격 프로필·통계·시간·사인을 저장. 기존 DEAD MEMORY 기록을 삭제하거나 잘못 읽지 않음. 저장 차단 시 탭 메모리로 폴백하며 결과 화면에 알림.
- 사망 빌드를 사용하는 추적자. 플레이어와 같은 기관/공격/변이 실행기를 사용. Patrol/Investigate/Chase/Attack/Retreat/Search, 시야·공격 소음·마지막 목격 위치, BFS, 후퇴 시 남은 체력 유지. 일반 런에서 100초 후 35% 확률. 기록이 있으면 입구 메뉴에서 테스트 출현(18초)을 켤 수 있음.
- 추적자 처치 시 실제 보유 기관 또는 현재 장착 기관에 호환되는 실제 보유 변이를 계승. 후보가 없으면 체력 강화.
- 정예 고기 집게의 갈고리/끌어당김/실패 후 빈틈, 5분에 도축장 주인 출현. 넓은 베기·갈고리·직선 돌진·지연 바닥 위험 구역의 네 패턴. 보스 처치 시 탈출 결과, 8분에는 시장 폐장/런 종료.

- `npm run check`, `npm run build:pages`: 새 모듈과 정적 산출물 검사. 별도의 하위 경로 `/dead-memory/` 브라우저 검사로 배포 경로 검증.

## 알려진 제한과 미구현

- 15~20분 정식 런 대신 명세에서 허용한 5~8분 테스트 런. 균형 잡힌 난이도나 다양한 빌드로의 실제 완주를 보증하지 않음. 체감 조작/적 밀도/성장 확률은 플레이 피드백이 필요함.
- 고정 아레나 한 개. 절차적 맵, 여러 지역, 돈/빚 메타 성장, 상점, 본격적인 3막 스토리 진행은 미구현. 몸값은 결과용 표시 수치이며 재화 경제가 아님.
- 임시 도형 아트와 짧은 합성 알림음. 정식 스프라이트/애니메이션/음악·전투 효과음은 미구현.
- 보스 돌진은 전조 후 선분 범위의 빠른 이동/판정이며 장시간 이동 애니메이션은 없음. 보스 패턴은 정해진 순서, 정예는 갈고리 한 패턴.
- 추적자는 최신 사망 1개를 재현하며 고급 전투 성향 학습/다중 추적자는 없음. 기본 원거리 거리 유지와 반격 변이 회피 행동만 구분.
- 브라우저 origin별 로컬 저장, 기록 최대 8개. 서버 동기화·다중 기기·클라우드 세이브·기록 관리 UI 없음. PC 키보드만 지원하며 게임패드/모바일 터치 미지원.
- GitHub Actions/Pages는 저장소 설정·플랜·권한에 따라 별도 활성화가 필요할 수 있음. 클라우드 환경 게시와 웹 배포는 별개.
