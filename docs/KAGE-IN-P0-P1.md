# KAGE//IN v3.0 — P0/P1 검토 및 결과

## P1 — 구현

수정 파일:

- `src/ninja.js`: 기존 Game의 충돌/피해/전조/투사체를 재사용한 닌자 시뮬레이션. 120Hz 고정 스텝, 히트스톱 중 키 edge/방향 보존, 별도 저장 키.
- `src/ninja-render.js`: 닌자·검·스카프, 잔상 3장, 칼날 호, 공중 그림자/높이 선, 띄우기·추격·격추, 적 전조 최상위 렌더.
- `src/ninja-game.js`, `src/ninja.css`, `index.html`: 출격/수련장/안내/일시정지, 키보드 선택, HP/충전/스타일/기세/공중 HUD, 흔들림·광원 줄이기, 기본 음소거와 짧은 타격음.
- `legacy.html`: 기존 화면 및 `src/game.js` 진입점을 보존. 기존 core/data/ActionMorph 모듈은 이번 단계에서 변경하지 않았다.
- `tests/ninja.test.js`, `scripts/ninja-browser.mjs`, `package.json`: P1 의미 있는 시나리오와 실제 키보드 회귀. 기존 브라우저 스크립트의 기본 URL만 legacy.html로 조정.
- `scripts/build-pages.mjs`, `scripts/build-standalone.mjs`: ninja 진입점/스타일 번들, 기존 페이지도 정적 산출물에 보존, 새 이름으로 오프라인 빌드.

구현한 동작:

1. Z1 0.08/0.07/0.14, Z2 0.09/0.07/0.17, Z3 0.11/0.09/0.20초. Z 홀드 반복, 전방 보정 50도, 적 1타당 1회 피격. Z3 작은 적 띄우기.
2. X 0.22초 이동/0.14초 무적, 2충전/2.3초 순차 회복. 활성 중 취소 금지, Z3 활성 끝 +0.06초 이후 취소. 벽 관통 금지.
3. 실제 적 공격이 X 무적으로 무효화될 때만 PerfectDodge. nonce당 1회. 0.7초 안에 다음 Z가 60px 전진 찌르기.
4. Space 0.52초 점프, 점프 무적 없음. 전방 220px 안 떠 있는 적에 방향키+Space 추격, 공중 연계마다 1회. 공중 검격 2타 후 0.3초 내 ↓+Z 선택 격추.
5. 공중 대상 6히트 상한, 띄우기 2초 ICD. 정예 0.45초 이내/보스는 공중 대신 경직 게이지로 환산.
6. 검격 3회 명중마다 기세(최대3), 추격 거리 보조, 미타격 감쇠. 스타일은 동작 다양성에 보상하며 동일 액션 반복의 점수 상승을 중단한다. P1에서는 스타일 XP 보너스/인술 개화가 없다.
7. 접근·측면·표창 닌자 실제 적 3종과 고정 표적 수련장. 첫 교전은 즉시 시작한다. C는 인술 공백 대신 4초 CD의 표창.

## 실행된 검증

- `npm test`: **107개 통과** = 기존 전투40 + 액션축19 + ActionMorph23 + 닌자25.
- `npm run check`: 기존/새 JavaScript 구문 검사 통과.
- `npm run build:pages`, `npm run build:standalone`, `npm run build:download`: 통과. ZIP CRC와 포함 HTML 일치 검사 통과.
- 새 실제 브라우저 검사: 메뉴/안내/수련장, WASD 미이동, Z 홀드 3타 띄우기, Space 추격, 공중 2타·격추, X 반복 키다운 1충전, C, 일시정지·설정, 실제 교전 3종/처치 통과. 스크린샷 `.local/browser/ninja/`.
- 단일 HTML: 외부 리소스 없이 로드 후 서버 종료·오프라인 상태에서 이동/Z/X/C 실행 통과.
- 기존 `test:legacy-browser`: 일반 전투/경험치 보상/실제 사망 저장/추적자/기존 톱날 미리보기 통과, 브라우저 오류 없음. 최종 닌자 단일 HTML에서도 새 키보드·공중 연계 브라우저 시나리오가 통과했다.

개발 중 실패/해결: 화면 캡처 중 테스트 시계가 계속 흘러 공중 검격 타이밍을 놓치는 문제는 수동 진행 시계로 검증했다. 별도로 두 번째 공중 검격 회복 중 격추가 막히던 실제 취소 규칙을 수정하고, 히트스톱 중 짧게 누르고 놓은 Z/Space와 방향 보존 회귀 테스트를 추가했다. 최종 단위/브라우저 연계 검사는 통과했다.

## 수동 플레이 체크리스트

- `npm start` → Enter 출격. Z만으로 근접 적 처치, 표창 전조를 보고 X로 회피.
- 수련장 → Z 홀드 3타 → 앞 방향키+Space → 공중 Z 홀드 → 2타 확인 후 ↓+Z. 점프/그림자와 격추 파동 확인.
- 일반 적 공격에 맞춰 X → 간파 알림 → 0.7초 내 Z. 빈 X에는 반격 알림이 없어야 한다.
- 점프 중에도 공격에 맞으며, X로 담장을 관통할 수 없어야 한다.
- Esc 정지/복귀, 흔들림 끄기/광원 줄이기, 기본 음소거. 키보드만으로 모든 메뉴 선택.

자동화 및 캡처 검토를 완료했다. 사용자의 손 감각 플레이테스트는 아직 받지 않았다.

## 남은 문제 / 다음 P2

- A/S/D/F 3인 링버퍼, V Invoke/2슬롯, 순수 FFF/WWW/LLL/VVV, 개별 CD, 보상 UI는 미구현. 인술은 지금 플레이할 수 없다고 화면에 명시한다.
- 인술16개 추가/속성 반응/개화, 12개 빌드, 스타일 XP, 고급 검술/회피는 P3–P4.
- P1은 무한 소규모 교전 프로토타입. 레벨업 성장/완성 5–8분 런/정예3종/새 철가면 보스/승리 목표는 P6까지 추가해야 한다.
- 카메라 스프링/일부 고급 음향/수련 튜토리얼 단계 개방과 세밀한 액션 튜닝은 남아 있다. 도형 플레이스홀더를 사용한다.
- 새 저장은 교전 요약만 기록한다. 이전 기관 빌드를 닌자 빌드로 변환하거나 추적자로 가져오지 않는다.
- 원격 main/Pages/새 닌자 다운로드 게시를 하지 않았다. 기존 MEAT MARKET 다운로드 링크는 기존 버전이다.
