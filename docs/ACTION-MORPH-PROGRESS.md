# ActionMorph v2.0 — 단계 A–C 결과

기준: Issue #2와 PR #1의 `docs/MEAT-MARKET-ACTION-EVOLUTION-v2.0.md`. 현재 JavaScript + Canvas 엔진과 방향키/Z/X/C를 유지했다. 기존 구현과의 차이 및 해석은 [감사 문서](ACTION-MORPH-AUDIT.md)에 기록했다.

## A — 비교·데이터 계약

수정 파일: `src/action-paths.js`, `src/data.js`, `docs/ACTION-MORPH-AUDIT.md`, 기준 사양서 사본.

32개 ID/8계열의 장비 참조와 화이트리스트 연산을 검사한다. 실제 실행 가능한 경로는 PATH_01/06/17/25 네 개다. 나머지 28개는 `implemented:false`이고 보상/연구실에서 제외한다. 기존 9기관/12변이의 ID 의미는 보존하며, 새끼 등·기생 심장·약점의 눈 3기관만 사용 가능하게 추가했다.

검증: 중복 경로, 계열 수, 슬롯 불일치, 미지원 연산, 계획 기관 장착 거절, 미구현 경로 선택 거절 통과. 남은 문제: 나머지 기관·변이·적응의 v1.3 완성은 단계 D 이후 필요하다.

## B — 공통 resolver·수명·보상·저장

수정 파일: `src/action-morph.js`, `src/action-paths.js`, `src/core.js`, `src/game.js`, `src/render.js`, `scripts/build-standalone.mjs`.

기존 attack/buffer/dash/specialAt lifecycle에 typed operation 해석기를 연결했다. 실제 형상과 벽 차폐, 액션별 hit ID, 연쇄 깊이 4/이벤트 예산 64, 지연 작업·로그·잔상·소환체 상한을 적용했다. 복제 공격은 재귀 proc을 차단한다. 장착 교체/사망 시 잔여 작업을 정리하며 장비 불일치 시 저장 티어를 유지한 채 휴면한다. 경로와 각 티어는 별도의 성장 보상으로 명시적으로 선택한다. 선택한 경로에 필요한 기관은 보상 우선 후보로 배치한다.

사망 레코드는 v2로 저장하며 v1 로드와 기존 변이 의미를 보존한다. 추적자는 저장 경로를 읽되 문서화된 안전 기본 공격을 사용한다. 적 전조는 빌드 이펙트 위에 그린다.

검증: 보상 게이트/한 경로 제한, 장착 해제·복구, 지연/소환체 cleanup, 구형 저장·미지 경로 fallback, 벽 차폐와 상한 테스트 통과. 남은 문제: 28개 예정 경로의 연산 확대와 추적자 경로별 AI는 아직 없다.

## C1 — PATH_01 회전 도살자

수정 파일: 경로 데이터, 공통 resolver, core 연동, Canvas 렌더러, `tests/morph.test.js`.

- T1: 세 번째 Z가 270°로 확장되며 짧은 전진과 0.12초 고정이 생긴다.
- T2: 공격 도중 X 취소 후 반원 베기. C 종료 후 2초간 등 칼날 가속.
- T3: Z 전후방 이중 궤적. C 당기기 후 3회 회전, 동일 대상 합산 피해 상한 적용.

검증: T0에서 맞지 않던 측면/후방 피격, 회피 무적과 충전 소모 보존, 회전 횟수·피해 상한 통과. 연구실 T0–T3 실제 키보드/Canvas 검사 통과. 남은 문제: 수치와 회전 가독성의 사용자 플레이테스트.

## C2 — PATH_06 뼈 저격수

수정 파일: 경로 데이터, charge input adapter/resolver, core 이동·발사 연동, 렌더러, 테스트.

- T1: 정지한 채 Z 0.45초 충전 후 놓으면 관통탄. 짧게 누르면 기본 탄.
- T2: X 즉시 충전 취소, 0.6초 내 재충전하면 50% 보존. C 표적 관통탄.
- T3: 0.9초 완충 시 더 좁은 레일탄과 보스 경직 게이지 +30. C 기본탄 뒤 3회 후속탄.

검증: 이동 중 축적 금지/속도 35%, 실제 관통 피격, 충전 보존·만료, 보스 경직, C 후속탄 수·피해 상한·쿨다운, 벽 차폐 통과. 연구실 T0–T3 검사 통과. 남은 문제: 표식이 없는 C는 전방 표적을 찾거나 기본 C로 복귀한다는 해석을 유지한다.

## C3 — PATH_17 잔상 검객

수정 파일: 경로 데이터, 잔상 생성·수명·복제 공격 adapter, 렌더러, 테스트.

- T1: X 직후 Z가 이동 경로 중간에 지연 잔상을 남긴다.
- T2: 실제 적 공격 회피 성공 이벤트에 추가 잔상. C가 각 잔상 위치에서 공격.
- T3: 끝점 잔상 2개가 0.8초 뒤 공격을 재현. C는 잔상을 소비해 플레이어와 연결하는 지면선 공격.

검증: 생성 조건·지연 시점, 최대 3개/3초 수명, 복제 proc 재귀 차단, C 소비와 선 생성, 교체 cleanup 통과. 연구실 T0–T3 검사 통과. 남은 문제: 다수 잔상과 적 전조가 겹치는 전투의 가독성 조정.

## C4 — PATH_25 새끼 사냥꾼

수정 파일: 새 기관 데이터, 소환체 AI/명령/HP·피격 adapter, core 적 공격 연동, 렌더러, 테스트.

- T1: Z 적중 표식으로 새끼 1마리 실제 돌진.
- T2: X 중 새끼는 회피하지 않고 공격을 유지해 피격 위험을 감수. C 전원 집중 명령.
- T3: 세 번째 Z 적중에 2마리 양방향 협공. C 3마리 집결 처형, 보스는 추가 피해로 처리.

검증: T0 소환과 T1 명령 구분, 실제 이동, X 중 적 탄환 피격, 집중/협공/집결 명령 수, 최대 3마리와 수명, 교체 시 제거 통과. 기생 심장의 초당 쿨다운 환급 상한과 약점의 눈 적용 대상도 검증했다. 연구실 T0–T3 검사 통과. 남은 문제: 소환체 목표 선택/생존 수치 플레이테스트.

## 통합 검증·다음 단계

- `npm test`: 기존 전투 40 + 기존 액션 축 19 + ActionMorph 23 = **82개 통과**.
- `npm run check`, `npm run build:pages`, `npm run build:download`: 통과.

- `test:morph-browser`: 네 경로 각각 T0/T1/T2/T3 **16개 시나리오 통과**, 브라우저 런타임 오류 없음. 스크린샷은 `.local/browser/morph/`.
- ZIP CRC 및 포함 HTML 일치 검사 통과. 최종 단일 HTML에서도 연구실 16개 시나리오가 통과했다. 외부 리소스 요청 없이 로드한 뒤 서버를 종료하고 네트워크를 끊어 기본 플레이가 계속되는 것도 검증했다.
