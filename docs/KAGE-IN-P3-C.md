첫 A는 화염 수리검을 즉시 발사한다. 둘째 A에는 발사가 없다. 셋째 A는 홍련폭을 요청하고 인을 비운다. 첫 기본기 자체가 CD여도 인은 쌓이며 3인 인술을 막지 않는다. 세 번째 조합이 CD/미구현/상태 불가여도 인은 초기화되고 이유가 표시된다. V/C/Enter를 인술 시전에 호출하지 않는다.

기본기 CD1초는 속성별 독립. 조합 CD5~10초는 인술별 독립이며 조합 시전 락0.18초. 단일기 짧은 회복0.12초로 첫 입력 직후 조합이 큐에서 실행될 수 있게 했다. 요청은 가장 오래된1개를 보존한다. 데이터상 큐 유효시간은0.18초이며 60Hz 틱 경계에서는 최대1틱 이내의 준비 판정을 허용하고, 여전히 불가하면 즉시 폐기/실패 알림을 낸다. 피격 경직 때문에 끝난 요청을 나중에 몰아서 발사하지 않는다.

## 이번 실제 인술 범위

- 기본 화염 수리검: 230px, 피해13, 점화3초.
- 기본 물 베기: 95px 전방 참격/약한 물리 밀기/젖음4초.

- 기본 진공 수리검: 195px, 소형 적 실제 수직 띄우기. 공중 시 하향 넉백.
- `NIN_001` 홍련폭: 전방 폭발/점화. `NIN_002` 격류진: 실제 플랫폼 표면의 파도, 공중은 수평 물칼날.
- `NIN_003` 천뢰격: 전방 시야/표식 대상 낙뢰. `NIN_004` 진공참: 상승 칼바람2개/공중 하향 변형. 같은 대상 중복 피해 차단.

파도는 연결된 플랫폼 끝에서 끝나며 허공 장판이 아니다. 발사체/근접/직선은 실제 플랫폼의 벽 차폐를 사용한다. 보스/중정예는 띄우기 대신 경직으로 환산한다. DOT는 직접 적중 이벤트·히트스톱을 재귀 생성하지 않는다. 원소 반응6종은 이번 단계에 없다.

## 실행 방법과 플레이 체크

`npm start` → Enter 성문 교전 또는 방향키로 수련장. ←/→ 달리기, Space 홀드 점프, ↓+Space 일방향 발판 내려가기. Z3→실제 점프→공중 Z/↓Z 포고. X는 벽을 통과하지 않고 공중에서는 착지 전1회. C는 지상 상향/공중 하향 피니시, CD2.8초.

A 1회만 눌러 즉발 후 0.75초 기다려 조합이 사라짐을 확인. AAA/SSS/DDD/FFF는 상위 순수기, ASD는 혼합기. V와 C 없이 동작해야 한다. 위쪽 조준과 점프 중 발사도 가능하다. ↑/↓로 지상 좌표가 이동해서는 안 된다.

키보드 자동화/캡처 검토와 실제 게임 시간180초 이상의 전투 시뮬레이션을 완료했다. 장시간 검사는 사망 시 교전을 재개하는 스트레스 테스트이며 무사망클리어/사람이 느끼는 손맛·재미를 검증했다고 주장하지 않는다. 사용자의 수동 플레이 확인은 남아 있다.

## 남은 P3-D/E

조합20개 중 **5개만 구현**, 나머지15개는 미리보기/실패 안내만 있다. 6종 환경 반응·4검술/4회피/8각인·8행동루프·미니보스·완성5~8분 구간은 아직 없다. 현재는 플랫폼 전투 테스트 구간이며 완성 P3로 보고하지 않는다. 체감 점프/발판 간격/적 난도와 카메라는 후속 플레이테스트로 조정해야 한다. 새 저장은 `kage-in.p3.v1` 교전 요약이며 이전 키는 읽거나 삭제하지 않는다.

원격 main/P2를 덮어쓰지 않는다. 전환 소스와 P3 실행 ZIP을 같은 별도 브랜치에서 검토하도록 유지한다. GitHub CLI 인증 확인은 실패했고, 실제 Draft PR 생성 요청도 `https://api.github.com/graphql`의 `Forbidden`으로 거절됐다. 차단을 우회하거나 main을 직접 변경하지 않았다.
