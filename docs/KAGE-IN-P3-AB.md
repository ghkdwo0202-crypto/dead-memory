# P3-A/B 체크포인트

기준: `design/kage-in-p3-sideview-auto-cast`의 `43f3744`, v3.1 요청서. P2 ZIP은 `docs/P2-SOURCE-AUDIT.md`에 출처/해시/실제 실행 모듈을 기록했다. `p2.html`과 `scripts/build-p2.mjs`로 기존 실행 경로를 보존했다.

P3-A 수정: `physics2d.js` 실제 60Hz 중력/AABB 서브스텝 충돌, 일방향 발판·코요테0.10·점프버퍼0.12·가변 점프·빠른낙하·낙사/체크포인트. `sideview-render.js` 독립 횡스크롤/패럴랙스 카메라. 플레이어와 적 어디에도 airHeight가 없다.

P3-B 수정: `side-events.js`, `sideview-core.js`의 Z3/공중2타/방향 베기/포고/C피니시/실제회피 반격/대시후35px돌파. 공중5히트·1회재띄우기·대형적경직환산. 작은 적3종+정예1종. `sideview-game.js`/`sideview.css`/index와 키보드 수련장·설정·보상. 새 저장 키 kage-in.p3.v1만 사용. 기존 ZIP/저장 키는 변경하지 않는다.

실행 결과: 기존135+물리5+횡스크롤17=157개 통과. 브라우저 실제 C띄우기/점프/포고/공중대시/벽막힘·점프넘기/Z3 타격 통과. npm check/Pages/단일HTML/ZIP 빌드 통과. 단일 공격 nonce, 실제회피에만 반격, 벽 차폐, 피해상태, 공중제한 테스트 포함.

3분 검증은 고정 스텝 시뮬레이션으로, 사망 시 테스트가 새 교전을 이어서 실제 게임 시간 180초 이상을 실행한다. 무사망 클리어나 사람의 재미 검증을 주장하지 않는다. 사용자 손맛·난도 확인, 후속 인술/새성장/보스는 남아 있다.

체크포인트 이후 P3-C의 단일즉발/0.75초결인/3번째자동발동/단일4+조합5를 순차 구현한다. P3-D/E 전체를 한 번에 구현하지 않는다. main 및 P2 원격 배포물은 보존한다.
