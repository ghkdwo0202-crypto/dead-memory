# Phase 1 — 톱날 액션 성장 축 v0.3

## 범위

사용자의 ‘성장할수록 액션이 변하는 빌드 축’ 요청에 따라 기본 톱날 팔 하나의 수동 전투를 확장했다. JavaScript/Canvas, 방향키/Z/X/C, 기관·자동 공격·저장·배포 코드는 유지했다. v1.3 전체 기관/변이/적응을 일괄 구현하지 않았다.

이전 미커밋 v0.3 진화/회복 물자/보스 확장 초안은 `.local/parked-v03-before-action-axis/`에 원본 파일·패치·SHA-256 목록을 보존하고 검증한 뒤, 해당 프로그램 파일만 마지막 배포 기준선으로 복원했다. 그 확장이나 실패 테스트를 삭제한 것으로 처리하지 않으며 이번 다운로드에는 섞지 않았다. v1.3 원문과 Phase 0 보고는 유지한다.

## 실제로 달라진 플레이

| 단계        | 획득/입력                       | 실제 동작과 선택                                                                                              |
| ----------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 기본        | 같은 적에게 Z 3회 적중          | 1·2·3타의 준비/회복과 베기 방향을 구분. 3타 피해 1.3배·넉백·출혈. 대상 변경/빗나감/1.3초 초과는 연격 초기화   |
| 톱날 운용 1 | 레벨업에서 선택, X → Z          | 대시 후 0.75초 내 Z는 65만큼 파고들며 베기. 대시당 한 번, 벽 충돌 준수, 추가 무적 없음                        |
| 톱날 운용 2 | 다음 강화 선택, 같은 적 3타 → C | 3타 적중 후 1.4초 내 C는 주변 적을 끌어모아 넓은 강화 회전 베기. 기존 C 쿨다운 유지                           |
| 톱날 운용 3 | 다음 강화 선택                  | 실제 공격을 X로 피하면 C 잔여 쿨다운 1.25초 감소(0.75초 내부 제한). C 실행 후 0.08초 회복으로 Z에 빠르게 복귀 |

강화는 자동 레벨 보너스가 아니라 **기관/변이 획득과 경쟁하는 보상 선택**이다. `ACTION_UPGRADES`에 단계와 창/거리/배율을 정의하고 `ARM_SAW_FLOW` 랭크로 관리한다. MUT01~12의 의미를 바꾸거나 새로운 가짜 MUT ID를 만들지 않았다. 팔을 바꾸면 톱날 동작은 비활성화되고 연격/마무리는 종료되며, 해당 팔의 강화 랭크는 보존되어 재장착 시 복원된다.

초기 피드백을 보기 위해 일반 추격 몬스터 HP를 30→55로 조정했다. 톱날의 기존 피해 22/범위 118은 유지했다. 따라서 v1.3 ARM01의 초기 수치 18/75와 완전히 일치한다고 주장하지 않는다. 치명타, 다중 대상 적중과 상태 틱 때문에 실제 몬스터 처치 횟수는 달라질 수 있다.

## 입력감/전투 기반 수정

- C/X가 히트스톱 프레임에 입력되면 소모되어 사라지던 문제를 수정. 시뮬레이션이 입력 처리 여부를 반환하고 UI가 다음 유효 프레임까지 단발 입력을 보존한다.
- 준비된 C 마무리는 3타 회복 중 예약할 수 있으며, Z 홀드 입력이 예약된 C를 덮어쓰지 않는다. 누적 경험치로 연속 레벨업할 때 다음 선택창이 숨겨진 채 멈추는 UI 처리도 수정했다.
- 후보 우선순위를 각도 → 거리 → 안정적 ID로 변경. 마지막 이동 바라봄을 별도로 보존하고 공격 활성 프레임 동안 시각 방향을 고정한다.
- 수동 공격/적 전조/투사체/위험 구역에 공격 인스턴스 ID를 전달한다. 같은 인스턴스의 중복 피해를 막고, 실제 무적 회피는 공격 인스턴스별 한 번만 발행한다. 귀환 투사체는 별도 복귀 인스턴스로 적중 가능하다.
- 무기별 버퍼 시간 사용, 대시 취소 구간 유지. 일시정지 메뉴에서 키보드로 공격 콘 표시를 켤 수 있다.
- 본 변경은 v1.3 전체 이벤트 처리 순서/킬 귀속/저장 마이그레이션을 완료한 것은 아니다.

## UI와 체험

전투 화면 아래에서 성장 단계, 같은 적 연격 횟수, X→Z 가능 상태, C 마무리 시간 바를 확인할 수 있다. 보상 카드에 다음 단계의 실제 동작을 표시한다.

시장 입구의 **완성형 톱날 액션 미리보기**는 3단계를 켠 별도 체험 런이다. 방향키로 메뉴 선택·Enter 확인으로 접근 가능하다. 이 모드는 사망 기록을 저장하지 않고 결과에도 명시한다. 일반 런은 랭크 0에서 시작하고 보상으로 성장한다.

## 저장 호환성

기존 사망 기록은 그대로 읽는다. 새 `upgradeRanksById`는 선택 필드이며 알려진 ID·정수·0~3만 복원한다. 과거 기록에 필드가 없으면 랭크 0으로 처리한다. 추적자는 저장된 랭크와 기관을 재현한다. 기존 변이의 v1.3 ID 충돌/환급 마이그레이션은 다음 장착 단계에서 처리해야 하며 이 작업에서 기존 ID를 재해석하지 않았다.

## 검증

실행 결과: 기존 40개 + 신규 19개 = **59개 통과**. 실제 Chromium의 키보드 전투·성장·3타→C·X→Z·저장/재시작 검사 통과. 구문/Pages/단일 HTML 빌드, ZIP 무결성, 서버 종료·네트워크 차단 후 기본 조작 검사도 통과했다.

- 기존 `tests/combat.test.js` 40개를 유지. 5분 시뮬레이션은 고정 프레임 수 대신 실제 게임 시간 300초 도달을 확인하도록 수정했다. 히트스톱이 늘어나도 실제 5분을 실행하며, 최대 반복 수와 보스/개체 제한 검증은 유지한다.
- `tests/action-axis.test.js` 19개: 같은 대상 적중/다중 대상/빗나감/시간 초과/복제, 단계별 해금, 대시 진입과 벽/무적, 마무리 창/쿨다운, C 우선 버퍼/히트스톱 입력 보존, 장착 변경/저장/추적자/미리보기 기록 차단, 조준/공격별 회피/중복 피해.
- 브라우저 검사는 기존 키보드 플레이와 새 성장 카드 선택, 미리보기에서 실제 3타→C와 X→Z를 검사한다.
- `npm run check`, `npm run build:pages`, `npm run build:standalone` 및 다운로드 ZIP 무결성/오프라인 실행을 별도로 확인한다.

## 남은 문제와 다음 단계

- 액션 축은 톱날 하나다. 가시 팔·다른 기관의 액션 축과 v1.3의 8종 대표 빌드는 미구현.
- 장착 환급·기관당 2변이 제한·적응 8종·완전한 저장 버전 이전은 아직 다음 Phase 범위다. 기존 피의 도살자 빌드 완료로 보지 않는다.
- 조작/연계의 자동 검증은 재미나 장기 밸런스를 보증하지 않는다. 첫 3분 성장 선택과 보스전에서 진입 거리/마무리 창/사망률을 실제 플레이로 조정해야 한다.
- 다음 작업은 이 한 축의 체감을 확인하면서 Phase 2 장착·환급 계약을 정리하는 것이다. 다른 기관을 한꺼번에 확장하지 않는다.
