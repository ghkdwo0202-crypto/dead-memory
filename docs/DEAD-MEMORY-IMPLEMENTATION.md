# 초벌 구현 범위

## 구현 방향

기존 저장소는 README만 가지고 있어 유지할 엔진·플레이어 코드가 없었습니다. 의존성 없는 Canvas + ES modules를 사용해 먼저 수직 슬라이스를 구현했습니다. 네이티브 PC 실행 파일은 제공하지 않습니다.

1. 맵·충돌·이동·기본 공격·2충전 대시·피해 피드백
2. 데이터 기반 스킬 실행기와 3슬롯/쿨다운
3. 이벤트 기반 공명 판정과 별도 시각 효과
4. 보상 후보 생성과 스킬 교체
5. 사망 기록 및 같은 실행기를 사용하는 추적자
6. 필수 케이스 자동 테스트와 실제 브라우저 검증

## 동작하는 기능

- 고정 전투방 3개, 두 통로, 장애물과 충돌, 적의 이동·공격 전조·정예 적
- A01 전방 화염 참격, M01 경로 돌진, S01 자동 공격 분신, D03 낙인/흡혈, D01 시간제 패링, C02 중력장 당기기/주기 피해
- R01: 돌진 적중 시 추가 폭발. 빗나가면 발동하지 않음
- R05: 돌진 경로 재현 피해와 분신
- R11: 낙인 대상 추가 화염 피해와 흡혈
- U01: 현재 R01의 성공을 확인한 후 추가 분신·참격만 실행. 돌진과 R01 피해는 반복하지 않음
- 연계는 이전 유효 액션 종료 기준. 스킬 시전 중·쿨다운 입력 거부. 기본 공격·이동·대시는 연계 유지
- 사망·패링·시야 상실 등에 따른 연계 중단, 동일 이벤트 중복 공명 방지
- 보상 후보 3개, 공명 연결 후보 보장(가능할 때), 스킬 중복 방지·슬롯 교체·즉시 공명 목록 갱신
- 실제 `localStorage` 사망 기록, 빌드·성공 공명·횟수·전투 통계 저장과 복원
- 추적자 1명: 최신 기록의 스킬, 성공한 공명만 실행. 기록 횟수에 따라 연계 선택 가중치 조정
- 추적자 Patrol / Investigate / Search / Chase / Combat / Retreat / Recover 상태. 시야·공격 소음·마지막 목격 위치 활용. 장애물/방 사이 BFS 경로 이동. 후퇴 시 체력 유지
- 추적자 보상은 실제 보유 스킬에서 생성. 전부 보유했다면 체력 강화로 대체
- HP, 대시, 스킬 쿨다운, 다음 입력 강조, 공명 알림, 추적자 체력/상태, 도움말·일시정지·빌드 UI

## 의도적으로 남긴 범위

- 나머지 14개 스킬, 17개 고유 공명, 7개 상급 공명은 **데이터 정의만 존재**하며 장착·보상·전투에서 제외됨
- 태그 기반 일반 공명 실행은 아직 없음
- 고정 맵이며 절차적 던전 생성·층 이동·보스·정식 밸런싱 없음
- 기억 제단은 현재 장식 오브젝트. 제단 상호작용·강화는 미구현
- 정예 전투 보상은 핵심 6종 후보 풀을 공유함. 별도 희귀도·희귀 스킬 풀 없음
- 공명 레시피는 보유 스킬에 따라 바로 표시됨. 별도 영구 발견 도감이나 추적자 레시피 해금 보상 없음
- 무기는 기억의 검 1종, 근접 적 1종과 체력/공격 강화 정예. 투사체/원거리 적 없음
- 추적자 시야는 원형 거리 + 장애물 선분 검사. 방향 시야각·경로 평활화·학습 모델 없음
- 간단한 도형 아트와 합성음 사용. 정식 스프라이트·애니메이션·음악·내보내기 빌드 없음
- 저장은 같은 브라우저의 같은 origin에 한정됨. 클라우드 동기화·다중 장치·설정 메뉴 없음
- 게임패드·모바일 터치·캔버스의 스크린리더 전투 조작은 미지원

2. 기억 제단 상호작용, 강화 데이터, 별도 공명 발견 도감 구현
3. 실제 스프라이트와 애니메이션·사운드 교체, 방별 적 구성 확대
4. 나머지 기술은 데이터만으로 효과를 정의할 수 있도록 액션 구성 확장 후 순차 구현
5. 절차적 방 생성과 네이티브 PC 패키징 여부 결정
