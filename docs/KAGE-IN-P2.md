## 실제 동작

- A/S/D/F는 화/수/뇌/풍. 한 keydown당 1회만 인정하며 마지막 3개 인을 유지한다. 입력만으로 이동/피해/무적/검격 취소는 발생하지 않는다.
- 3인 조합 미리보기는 순서 무관. V로 준비하면 버퍼를 비우고 앞 슬롯에 넣는다. 기존 앞 슬롯은 뒤로 이동하며 같은 인술은 중복 없이 앞으로 승격한다. 빈 결인 상태의 V는 두 슬롯을 교대한다.
- C는 앞 슬롯 인술. 준비가 없으면 기존 4초 표창. 각 인술 CD와 전역 0.2초 CD를 모두 검사한다. 교대/재준비로 CD를 초기화할 수 없다.
- V는 공격 종료/회피 종료를 최대 0.2초 기다린다. C도 취소 가능 구간/공중 상태에 따라 최대 0.2초 대기한다. V+C 동시 입력은 준비를 먼저 처리한다. 상태/표적/용량이 불가하면 인술 슬롯과 CD를 소비하지 않는다.
- 피격 시 대기 중인 V/C는 취소하지만 세 인은 유지한다. V 대기 중 인이 바뀌면 준비를 취소하며 예전 슬롯을 몰래 시전하지 않는다.

| 인술 | 실제 기능 | 제약 |
| --- | --- | --- |
| NIN_001 화둔·홍련폭 (A A A) | 전방 폭발, 밀어내기, 3초 점화·0.5초 DOT, 과열 카운터 | 지상만, CD 5.5초, 과열 3 상한 |
| NIN_002 수둔·격류진 (S S S) | 220px 이동 파도, 4초 젖음, 적 밀기 | CD 6초, 벽 차폐, 보스 밀기 면역 |
| NIN_003 뇌둔·천뢰격 (D D D) | 전방 표식 우선 단일 낙뢰, 3초 감전, 공중 경직 | CD 7초, 전방 ±70°/440px/시야 표적 필요 |
| NIN_004 풍둔·진공참 (F F F) | 실제 2갈래 이동 칼바람, 풍표식, 작은 적 띄우기→Space 추격 | CD 5초, 한 대상 1회, 띄우기 2초 ICD, 보스는 경직 +25 |

화둔 외 3종은 지상/공중에서 사용할 수 있다. 판정은 렌더 이펙트와 분리하며 적 전조는 여전히 최상위에 그린다. 투사체는 기존 표창과 인술을 합쳐 350개 상한이고 시전 중 필요한 공간을 예약한다. 인술도 공중 6히트 상한에 포함한다. DOT는 직접 피격 이벤트나 반응을 재귀 생성하지 않고 매 틱 히트스톱도 만들지 않는다.

정상 모드에서는 네 인이 모두 개방된다. 선택형 **결인 입문 모드**는 A/S로 시작하고 수련 60초에 D, 90초에 F를 개방한다. 이 옵션은 정식 모드의 레시피/보상 잠금과 분리했다.

실제 XP 수집으로 성장 3택을 표시한다. 활력(최대HP/회복), 경공(이동), 호흡(회피 충전/남은 CD 감소)은 P2의 기반 보상이다. 검술 스타일/회피 변형/진화 패시브 12빌드를 구현했다고 보지 않는다.

- 최종 단일 HTML에서도 같은 `test:seals-browser` 전체 시나리오 통과.
- `npm run test:browser`: P1 Z3→Space→공중2타→격추, 회피·표창·설정·적3종 회귀 통과.
- `npm run test:offline`: 외부 리소스 없이 HTML 하나 로드 → 서버 종료/네트워크 차단 → 결인/풍둔/실제 띄우기/Space 추격 통과.

개발 중 발견/수정: 점화 DOT에도 전체 게임 히트스톱이 걸리던 문제를 직접 공격으로 제한했다. 지연 Invoke가 바뀐 인을 사용하거나 대기 C가 이전 슬롯을 시전할 수 있던 경우를 차단했다. 투사체 한도에서 시전만 소비되는 경우를 사전 검사/공간 예약으로 막았다. 각각 자동 회귀 시나리오를 추가했으며 최종 실패는 없다.

## 직접 확인할 플레이

1. 검술 수련장 → A A A → V → C: 전방 폭발/점화/밀려나는 표적.
2. S S S → V → C: 앞 슬롯이 수둔, 뒤 슬롯이 화둔. V만 눌러 교대하면 두 CD가 그대로여야 한다.
3. D D D → V → C: 전방 표적 낙뢰. 반대로 바라보고 표적이 없을 때는 CD가 소비되지 않아야 한다.
4. F F F → V → C → 앞 방향키+Space: 칼바람으로 띄운 적을 실제 추격.
5. 공격 도중 결인, V+C 동시 입력, Esc 정지/복귀, 성장 선택을 마우스 없이 수행.

위 시나리오는 실제 브라우저 키보드 자동화와 캡처 검토로 확인했다. 사용자 손 감각 테스트는 아직 받지 않았다.

## 미완료 / 다음 P3

혼합 16개 인술은 **레시피 이름/미리보기만** 있으며 준비/시전을 막았다. 전체 20개 레시피 검증 통과가 20개 인술 전투 완료를 의미하지 않는다. Wet→Lightning/Fire+Wind/과부하 등의 속성 반응, 개화 operation, 과열을 활용하는 후속 루프는 P3에서 구현한다. 이번 과열은 카운터만 있다. 12빌드/고급 보상은 P4, 새 보스/완성 런은 후속 단계다. 새 죽음 저장은 기존 키를 건드리지 않는 교전 요약을 유지하며 인술 슬롯은 새 런에서 초기화한다.
